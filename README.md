# Recipe_ChatBot

**Recipe_ChatBot** is a conversational AI system built using Retrieval-Augmented Generation (RAG) and integrated with a Large Language Model (LLM) to generate personalized food recipes based on user input. The system is implemented using **LangChain** for orchestration and **FastAPI** for deployment as an accessible web API.

This chatbot was developed as part of my graduation project, **SaveBite** — an innovative application designed to reduce food waste through intelligent inventory tracking and dynamic recipe suggestions.
